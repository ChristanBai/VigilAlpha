# dev.18 更新安装

这是现有 VigilAlpha 的更新包。目标版本为 `0.1.0-dev.18`；下载成功不等于安装成功。

## 在目标 Mac 上操作

1. 从 [dev.18 GitHub Release](https://github.com/ChristanBai/VigilAlpha/releases/tag/v0.1.0-dev.18) 下载完整 ZIP 和 SHA-256 文件，先核对校验和再解压。不要使用旧的 dev.16 包。
2. 打开解压文件夹，运行 `Install-on-Mac.command`。若双击不能执行，打开终端，输入 `bash `，将该文件拖入终端，再按回车。此步骤需要已安装 Node.js 22+ 与支持插件的 Codex CLI；安装脚本会明确报告缺少的依赖。
3. 等待校验、测试和插件安装完成。终端须出现“已核验插件文件”和源版本 `0.1.0-dev.18`，插件列表须有 `vigilalpha-codex@vigilalpha`。出现错误时安装未完成，请保留错误信息。
4. 重启 Codex／ChatGPT 桌面应用，在新任务中启用 VigilAlpha，发送：**“检查设置与运行版本，确认当前运行 0.1.0-dev.18。”** 须以运行工具返回的版本为准。

安装器把发布文件放入 Mac 的固定目录，保留旧发布目录，校验插件安装文件与本次 ZIP 一致；不会自行重置券商账户或填写密钥。更新时若同名 `vigilalpha` marketplace 指向旧发布目录，安装器会切换到本次目录；后续步骤失败时会尝试恢复原来源，并明确报告结果。

## 安装后的功能边界

dev.18 仍为只读研究插件。安装成功不会自动连接 Chrome，也不会增加订单执行接口。通过独立授权的浏览器操作完成的券商模拟订单，须另外记录，不可当作插件自动下单已完成。

Kronos 的 Python 环境及模型权重需要另行配置。未配置时，不能宣称完整模型实验能力已在 Mac 上就绪。

安装器已完成发布包文件校验和 Linux 拒绝误装检查，尚未完成目标 Mac 的端到端安装验收。
