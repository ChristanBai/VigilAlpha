# VigilAlpha：长期产品目标

更新时间：2026-11-05。此文记录产品方向；能力是否完成须以代码、部署和实际运行记录分别核验。

## 产品要为用户完成什么

帮助 Trading 212 Invest 用户发现和理解投资机会，形成有证据、可执行、可复核的投资决策；持续记录交易与结果，验证能否提高扣除全部成本后的投资回报，并控制风险、保护账户与研究数据。

长期追求净收益增长，不能承诺每笔盈利、永不亏损或未来必然盈利。利润、回撤、资金占用和基准表现共同决定产品是否增加价值。入金不能记为投资收益。

## 六项长期能力

1. **账户事实与可视化**：连接或导入真实账户，核对现金、持仓、成本和历史成交；在 K 线/折线上展示成交、平均成本与组合风险，让收益来源可解释。
2. **机会研究与信息更新**：结合新闻、公告、财报、估值及行业关系回答投资问题。对 Apple、SpaceX 等上下游问题，区分直接关系、间接关系和传闻，核验上市主体及用户账户中的证券可交易性；关联本身不等于投资价值。
3. **明确决策规则**：结合趋势、动量、均值回归、波动回撤、集中度、公司质量与估值，输出买入、持有、减仓、退出或等待的条件、依据、反证、仓位和失效条件。缺少必要证据时等待。
4. **交易执行**：先在 Invest Practice 验收信号、订单、成交和账本；长期建设受授权、券商规则和风险边界约束的自动执行。模拟、实盘和离线假设成交分别记录。实盘权限不由模拟授权推定。
5. **验证、复盘与学习**：冻结规则后开展历史检验和前瞻观察，纳入费用、价差、滑点、汇率、税费、分红及公司行动；与同口径买入持有比较，保留亏损、失败和未成交。学习提出候选改进，经独立验证后再晋级，不因短期盈利自动改动规则。
6. **稳定、安全与交付**：保护凭据、账户数据和私有代码，维持可回退安装与运行记录。开源复用须核验许可、来源与实际效果，为未来付费产品保留可行的分发路径。

## 产品如何区别于券商现有功能

把研究证据、账户约束、条件决策、执行和结果验证连起来，回答：为什么采取这项行动，何时判断失效，成本后有无增加价值，以及下一轮是否应保留该规则。新增图表或模型名称本身不构成差异化成果。

## dev.18 在长期目标中的位置

dev.18 是开发预发布版，包含只读账户研究、候选规则验证、财报计算与 Kronos 实验调用等模块。

- 券商接口仍为只读，未实现产品自身的订单提交。
- 本机 Chrome 的控制取决于宿主提供实际连接；安装普通依赖不会自动授予该连接。
- 安装包、安装命令成功、宿主加载新版本仍分别验收，不能互相替代。
- Kronos 权重和 Python 实验环境不随轻量 ZIP 分发，须单独配置和验证。
- 目前没有本轮券商模拟成交记录，未证明策略能持续盈利。

当期任务是交付路径上的阶段目标，不能用它替代上述长期目标。
